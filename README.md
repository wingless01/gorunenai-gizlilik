# GörünenAI yasal metinleri

- Gizlilik politikası (Türkçe, English): https://wingless01.github.io/gorunenai-gizlilik/
- Kullanım şartları: https://wingless01.github.io/gorunenai-gizlilik/kullanim-sartlari/
- Hesap ve veri silme: https://wingless01.github.io/gorunenai-gizlilik/hesap-silme/

Her sayfanın sağ alt köşesinde bir erişilebilirlik paneli var: sesli okuma,
yazı boyutu, kontrast modları, okuma kolaylıkları ve engel türüne göre hazır
profiller. Panel harici hiçbir kaynak yüklemez ve veri göndermez; ayarlar
yalnızca ziyaretçinin tarayıcısında saklanır.

Bu sayfalar GörünenAI projesindeki `gizlilik/` klasöründen üretilir (`gizlilik/uret.py`).
Elle düzenlemeyin; metni orada değiştirip yeniden üretin.
